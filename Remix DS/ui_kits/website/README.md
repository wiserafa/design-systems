# Luminova Website — UI Kit

Recreation do site institucional da Escola Luminova Interlagos. **Como o cliente não forneceu um codebase ou Figma, esta é uma interpretação fiel das diretrizes** (paleta, tipografia, padrão eyebrow+headline, blobs, footer roxo) aplicada a um layout típico de escola K-12.

Surface: marketing / institucional. Audiência: famílias considerando a Luminova.

## Files

- `index.html` — landing principal com header, hero, segmentos, novidades, CTA, footer
- `Header.jsx` — header sticky com nav e CTA laranja
- `Hero.jsx` — hero institucional com blobs decorativos
- `SegmentCards.jsx` — 4 cards de segmento (F1/F2/EM/Profs), cada um colorido
- `NewsGrid.jsx` — grid de novidades / agenda
- `CtaBlock.jsx` — bloco roxo sólido com call-to-action
- `Footer.jsx` — footer roxo com links

## Components shown

Header sticky · Hero com eyebrow + headline + blobs · Cards de segmento coloridos · Grid de cards de novidades · Bloco CTA roxo · Footer institucional roxo · Botões primário e CTA · Badges de segmento.
