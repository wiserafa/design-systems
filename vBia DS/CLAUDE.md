# Luminova V_Bia — project rules

## Typography (strict)
- **Numbers always use Museo Sans Rounded** (`--font-numeric` / `--font-body`) — years, counts, stats, prices, dates, percentages. Never set numerals in Arista Pro.
- **Arista Pro Alternate is only for logos and titles/headlines.** All UI text (buttons, badges, labels, captions) and body copy use Museo Sans Rounded.
- The Arista trial font has no numeral glyphs (digits render blank), which reinforces the rule above.
